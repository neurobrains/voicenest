# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.2.0] - 2026-03-02

### Added
- Initial VoiceNest voice widget implementation
- Support for Daily and SmallWebRTC transports
- Pipecat integration for voice conversations
- Embeddable widget with customizable themes
- CDN-ready distribution build
- Automatic build and publish workflow

### Features
- Real-time voice conversation capability
- Multiple transport options (Daily, SmallWebRTC)
- Customizable UI themes (dark/light)
- Position and styling options
- Error handling and user feedback
- Microphone permission management
- Test mode for UI development

### Technical
- Webpack build configuration
- NPM package setup for CDN usage
- ES6 module structure
- CSS styling with themes
- Cross-browser compatibility
